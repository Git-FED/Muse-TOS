# Add-Action Prompt

> Add the one action type the user just named — and only that action. Ask for its description, the platform it targets, and what the action involves: does it include a link, a payment, an account, or personal data? Record it in the `templates/action-template.json` shape. Check the platform's rules are already snapshotted by the tracker — if not, mark that action **UNCHECKED** until the tracker runs, and say so. Do not guess what the action involves and do not add actions the user did not name.
