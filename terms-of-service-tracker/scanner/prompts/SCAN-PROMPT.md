# Scan Prompt

> Scan this action **BEFORE** it is taken. Load the action the user described and the platform it targets. Load that platform's rule text from the tracker's snapshots — if no snapshot exists, say **UNCHECKED** with the reason and stop; never guess the rules. Compare the action against each rule, one by one. Output one verdict: **CLEAR**, **CONFLICT**, **CONTRADICTION**, or **UNCHECKED**. For CLEAR, CONFLICT, or CONTRADICTION, quote the exact rule text, its source, and its snapshot date for every rule you used. If a person told the user the action is fine but a written rule says otherwise, that is CONTRADICTION — quote both, and the written rule wins. Never scan an action that already happened and call it a pre-check. Label the verdict **VERIFIED** only if you checked it by hand with live evidence; otherwise **UNVERIFIED**.
