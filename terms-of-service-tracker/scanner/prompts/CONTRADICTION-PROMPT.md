# Contradiction Prompt

> Check whether a human instruction contradicts the written rules. Quote both sources in full: first, the human instruction — who said it, where they said it, their exact words; second, the written rule — exact text, its source, and its snapshot date. If they disagree, the verdict is **CONTRADICTION** and the written rule wins — say so plainly. A person saying “go ahead” is never proof that the action is allowed; only the written rule counts. Explain what the user risks if they follow the human instruction (the rule as written, e.g. removal or ban for repeat offenders), and what would make the action safe (the rule changing, or written permission from the same authority). Never treat a verbal okay as permission. Label **VERIFIED** only if both quotes were checked by hand with live evidence; otherwise **UNVERIFIED**.
