# Fedpromptly Static Site

The static site lives here. Start with the repository [landing page](../README.md), then open [index.html](index.html) for the animated local demo.

The site includes the symbol favicon, looping ticker, animated dark effects, promotional SVGs, an animated GIF, age-gated support flows, centered Discord presentation, the protected Discord server-buttons page, and an optional Supabase-backed join page.

Deploy `site/` to GitHub Pages or use it as the static output directory for Cloudflare Pages/Workers. No hosted URL is claimed by this repository.
